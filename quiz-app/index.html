把考试题变成自己的题库

学习通只有考试/作业时才能看到题。用浏览器油猴脚本在答题页导出 JSON，再导入这里就能无限重考。

📌 随机组卷（每次题不一样）：每次考完都导出 JSON，可一次选多个文件导入自动合并，或点「合并全部题库」去重汇总。

  1. 安装 Tampermonkey（油猴）
  2. 安装项目里的 userscript/chaoxing-export.user.js
  3. 打开学习通考试/作业页，点右下角「下载 JSON 题库」
  4. 交卷后再打开「查看成绩/答卷」页导出一次（带答案）
  5. 回到本页导入 JSON 文件
