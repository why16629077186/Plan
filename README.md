# 学习通本地刷题

学习通上的题通常只在**考试/作业/章节测验**时才能看到，没有单独的题库下载入口。这个项目提供：

1. **油猴脚本** — 在答题页一键导出 JSON 题库  
2. **本地刷题页** — 导入 JSON 后无限重考、看解析、随机顺序

## 快速开始

### 第一步：安装导出脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）
2. 点击油猴图标 →「添加新脚本」→ 把 `userscript/chaoxing-export.user.js` 的内容粘贴进去保存  
   （或直接拖拽该文件到油猴管理页）

### 第二步：考试时导出题目

1. 打开学习通的**考试 / 作业 / 章节测验**页面（答题中即可）
2. 页面右下角会出现 **「导出到本地刷题」** 面板
3. 点击 **「下载 JSON 题库」**

> **关于答案：** 考试中往往看不到标准答案。交卷后打开 **「查看成绩 / 答卷详情」** 页面，再导出一次，JSON 里会带上正确答案和解析。  
> 也可以先导出无答案版本练手，之后再导入带答案版本覆盖。

### 第三步：本地刷题

用浏览器打开 `quiz-app/index.html`（双击即可，无需服务器）：

1. 点击 **「导入 JSON」** 或 **「导入 Word」**（`.docx` 可直接从微信保存的文档导入）
2. 一次可多选 `1.docx`、`2.docx`、`1(1).docx` 等文件，自动合并去重
3. 选择题库 → **开始刷题**
4. 做完点 **交卷**，可 **重新考试** 无限刷
5. 随时点 **Word / Anki** 导出

### 导出格式

| 格式 | 用途 | 怎么用 |
|------|------|--------|
| **Word** | 打印复习、传手机 | 用 Word/WPS 打开 `.doc` |
| **Anki** | 间隔记忆长期背 | Anki → 导入 → 选 `.txt` 文件 |
| **JSON** | 备份、换电脑 | 重新导入刷题页 |

可先导入 `sample/sample-bank.json` 体验功能。

## 支持的题型

| 题型 | 导出 | 自动评分 |
|------|------|----------|
| 单选题 | ✅ | ✅ |
| 多选题 | ✅ | ✅ |
| 判断题 | ✅ | ✅ |
| 填空题 | ✅ | ✅ |
| 简答题 | ✅ | 不评分（自行对照） |

## 常见问题

**Q: 脚本显示「未识别到题目」？**  
学习通页面结构经常更新。确认你在答题页或查看页，刷新后等几秒。若仍不行，可尝试 [Chaoxing-Exam-Extractor](https://github.com/2281046977/Chaoxing-Exam-Extractor) 等工具导出后再手动整理为 JSON。

**Q: 题目出现乱码？**  
部分课程用了字体加密。需使用带字体解密功能的导出工具，或交卷后在「查看答卷」页导出（该页通常已解密）。

**Q: 题库存在哪？**  
刷题页的题库保存在浏览器 `localStorage`，换电脑需重新导入 JSON。
